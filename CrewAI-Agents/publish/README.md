# Publish — LinkedIn content for the QA Bug Triage Crew

Two files for sharing your AI agent project:

## 1. `linkedin_post.md`
Ready-to-paste LinkedIn post text. Copy everything under **"Post text (copy-paste ready)"**.

## 2. `linkedin_card.html`
A self-contained HTML share card sized **1200×630** (LinkedIn's recommended image ratio). It renders the crew pipeline as a visual image.

**How to turn it into an image:**
1. Open `linkedin_card.html` in a browser (double-click it).
2. Zoom to 100% / reset (Ctrl+0).
3. Take a screenshot of the page, or use DevTools:
   - Press F12 → click the device toolbar icon (Ctrl+Shift+M)
   - Set dimensions to **1200 × 630**
   - Click the camera icon (Capture screenshot)
4. Save the PNG and attach it to your LinkedIn post.

> No external fonts or images are used — it renders fully offline.
